# 使用Customer Journey Analytics的內嵌分類

CJA的內嵌分類可讓您直接在Analysis Workspace中進行即時編輯，方法是更新表格中的值或將多個值分組在一起。 它將一小段但強大的衍生欄位功能直接帶入Workspace體驗。
