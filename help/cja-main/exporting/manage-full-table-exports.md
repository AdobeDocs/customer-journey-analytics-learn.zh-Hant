# 管理及管理完整的表格匯出

瞭解如何在Customer Journey Analytics中管理完整的表格匯出。  這些功能可讓CJA管理員簡化監督、減少手動檢查、增強自動化，並確保將可靠的資料傳送到雲端目的地。 如需詳細資訊，請瀏覽[檔案](https://experienceleague.adobe.com/en/docs/analytics-platform/using/cja-workspace/export/export-cloud){target="_blank"}。
